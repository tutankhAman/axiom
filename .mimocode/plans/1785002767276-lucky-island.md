# Phase 0 — Environment Setup (Guide)

User executes each step. I guide and troubleshoot.

## Already Done
- EnergyPlus v26.1.0 at `/usr/local/EnergyPlus-26-1-0`
- `pyenergyplus` imports with `PYTHONPATH=/usr/local/EnergyPlus-26-1-0`
- GPU confirmed: GTX 1650, 4GB VRAM

## Steps

### 1. Install Ollama
```bash
curl -fsSL https://ollama.com/install.sh | sh
```

### 2. Start Ollama service
```bash
ollama serve &
```

### 3. Pull model
```bash
ollama pull qwen2.5:3b-instruct
```

### 4. Verify GPU offload
```bash
ollama ps
nvidia-smi
```
Check `ollama ps` shows "GPU" in PROCESSOR column.

### 5. Test tool-call round trip
```bash
curl http://localhost:11434/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen2.5:3b-instruct",
    "messages": [{"role": "user", "content": "What is the zone temperature?"}],
    "tools": [{
      "type": "function",
      "function": {
        "name": "get_zone_state",
        "description": "Get temperature and comfort data for a zone",
        "parameters": {
          "type": "object",
          "properties": {
            "zone_id": {"type": "string", "description": "Zone identifier"}
          },
          "required": ["zone_id"]
        }
      }
    }]
  }'
```
Look for `tool_calls` in the response with a valid `get_zone_state` call.

### 6. Persist PYTHONPATH
```bash
echo 'export PYTHONPATH=/usr/local/EnergyPlus-26-1-0:$PYTHONPATH' >> ~/.bashrc
source ~/.bashrc
```

## Exit Criteria
1. `pyenergyplus` imports — DONE
2. `nvidia-smi` shows model on GPU — after Step 4
3. One valid tool-call response — after Step 5
